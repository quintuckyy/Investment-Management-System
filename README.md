# Investment Database System 

A full-stack database-focused application for managing investors, investment accounts, deposits, withdrawals, stock orders, portfolio holdings, audit logs, and SQL-based reports.

# Tech Stack

- PostgreSQL
- Django REST Framework
- React TypeScript
- Tailwind CSS

# Main Features 

- Investor management
- Account management
- Deposit and Withdrawal transactions 
- Stock buy/sell orders
- Portfolio holdings 
- SQL reports 
- CSV import /ETL
- Audit logs
- Data validation
- Reusable database views for financial reporting
